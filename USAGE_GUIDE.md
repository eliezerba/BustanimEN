# Usage Guide

## What This Dashboard Covers
This English-language dashboard supports research workflows for:
- Historical Orchard records
- Orchard Fruit Trees
- Non-Orchard Trees
- Agricultural Installations
- Terraces
- District-level spatial analysis using modern Israeli administrative districts

## Important Language Note
The interface is English-only.
Some raw values in source data may originate in Hebrew, but visible labels are translated to English.

## Main Workflow
1. Open map and layer panel.
2. Select main display groups.
3. Expand groups to toggle individual types.
4. Use search, selection, and charts for exploration.
5. Use district and species tools for deeper analysis.

## Layer Panel Behavior
- Main layers are shown as collapsible groups.
- Individual types can be toggled independently.
- Optional source layers are available for review workflows.

## Tabs
- Overview
- Historical Orchard
- Districts
- Orchard Fruit Trees
- Analytics
- Advanced
- Compare

## Basemaps
- OSM Modern
- Satellite (Esri)
- Historical map variants (Palestine Open Maps)

## Exports
- CSV export is available from the layer/map panel.

## Troubleshooting
- If data does not load, check network/API availability.
- If map appears empty, verify active layers and filters.
- If running locally, use `node server.js` and open http://localhost:3000.
