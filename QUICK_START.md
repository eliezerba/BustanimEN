# Quick Start

## 1) Open Terminal
Use PowerShell/Terminal in the BustanimEN folder.

## 2) Start Local Server
```bash
node server.js
```

## 3) Open in Browser
http://localhost:3000

## 4) First Checks
1. Confirm map loads.
2. Open Layers & Map panel.
3. Toggle main groups and individual types.
4. Click a map object and verify details.

## If Something Fails
- Refresh browser.
- Check console for errors.
- Confirm network/API access.
- Ensure server is running in the correct folder.

## Stop Server
Press Ctrl+C in terminal.
